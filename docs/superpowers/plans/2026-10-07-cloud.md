# Grill Me Extended Cloud Implementation Plan

> **For agentic workers:** Execute this approved plan inline with executing-plans; user authorized implementation in this session.

**Goal:** Deliver a remotely callable MCP questionnaire with host-driven interviewing and cloud deployment packaging.

**Architecture:** Reuse the tested session store and document materializer behind a server factory. Authenticated HTTP requests select an isolated persistent user store; MCP Apps UI writes through the same tools. GitHub OAuth protects the service; expiring signed links deliver documents.

**Tech Stack:** Node 22+, TypeScript, MCP SDK, MCP Apps, Express, GitHub OAuth, Docker/Caddy.

**Spec:** ../specs/2026-10-07-cloud-design.md

## Global Constraints
- ChatGPT performs interviewing and self-review. No model API calls or required subagents.
- Single process and single replica with a persistent disk; 3–7 questions, 12-round gate, revision and idempotency protections.
- Production HTTPS and OAuth; unauthenticated development binds only 127.0.0.1.
